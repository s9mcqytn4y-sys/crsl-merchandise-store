# Aturan Delegasi Agen (Agent Delegation Rules) — CRSL Store v2

Panduan ini membagi peran dan tanggung jawab antar agen spesialis untuk efisiensi pengembangan.

## Subagen Spesialis & Tanggung Jawab

| Subagen | Berkas Agen | Spesialisasi Utama |
| :--- | :--- | :--- |
| **arsitek** | `.agents/agents/arsitek.md` | Perancangan arsitektur Modular Monolith, skema PostgreSQL, dan integrasi driver Biteship/Midtrans. |
| **peninjau-kode** | `.agents/agents/peninjau-kode.md` | Tinjauan kualitas kode, konvensi penamaan Bahasa Indonesia, dan antislop UI/UX. |
| **panduan-tdd** | `.agents/agents/panduan-tdd.md` | Memandu siklus pengujian Red-Green-Refactor dan pengujian fitur Laravel. |
| **penyelesai-error** | `.agents/agents/penyelesai-error.md` | Diagnosa exception runtime PHP/Laravel, error PostgreSQL, dan error build Vite/React. |
| **peninjau-keamanan** | `.agents/agents/peninjau-keamanan.md` | Audit OWASP, keabsahan transaksi pembayaran Midtrans, dan sanitasi input. |
| **pembersih-refaktor** | `.agents/agents/pembersih-refaktor.md` | Eliminasi dead code, optimasi import TypeScript, dan penyederhanaan komponen. |
